# Telurio Company 🎟️

**Plataforma digital de venda de ingressos para eventos.**

A Telurio Company é um projecto de desenvolvimento web orientado para a divulgação de eventos e a comercialização de ingressos através de uma experiência digital intuitiva, moderna e acessível.

O objectivo é simplificar a forma como os utilizadores descobrem eventos e acedem às respectivas informações, criando uma base para uma plataforma de bilhética digital.

## 📌 Sobre o projecto

A plataforma pretende aproximar organizadores de eventos e participantes, disponibilizando uma interface para consultar eventos e, conforme as funcionalidades implementadas, adquirir ingressos online.

O projecto está organizado num repositório GitHub com uma pasta dedicada ao frontend.

## ✨ Funcionalidades

A plataforma pode contemplar as seguintes funcionalidades, de acordo com a implementação:

- Apresentação e consulta de eventos.
- Visualização de informações sobre eventos.
- Apresentação dos ingressos disponíveis.
- Processo de aquisição de ingressos.
- Interface responsiva para computadores e dispositivos móveis.
- Integração com meios de pagamento, quando configurada.
- Gestão de eventos e vendas, caso exista backend administrativo.

As funcionalidades devem ser confirmadas no código antes de serem consideradas concluídas.

## 🚀 Instalação e execução

### Pré-requisitos

- Git.
- Node.js, caso o frontend utilize uma stack JavaScript ou TypeScript.
- npm ou o gestor de pacotes definido pelo projecto.

### 1. Clonar o repositório

```bash
git clone https://github.com/josuebalthazarbalthazar-spec/teluriocompany.git
```

### 2. Aceder ao frontend

```bash
cd teluriocompany/frontend
```

### 3. Instalar as dependências

Se existir um ficheiro `package.json` nesta pasta e o projecto utilizar npm:

```bash
npm install
```

### 4. Iniciar o ambiente de desenvolvimento

Se o projecto tiver um script `dev` configurado:

```bash
npm run dev
```

Abre no navegador o endereço local indicado no terminal.

### 5. Criar a versão de produção

Se existir um script `build`:

```bash
npm run build
```

**Nota:** confirma os comandos disponíveis no `package.json` antes de executar estes passos.

## 🔐 Segurança

Boas práticas recomendadas para uma plataforma de bilhética:

- Validar os dados recebidos pelo servidor.
- Proteger os dados pessoais dos utilizadores.
- Nunca expor chaves privadas no frontend.
- Utilizar serviços de pagamento adequados, se aplicável.
- Prevenir compras duplicadas e manipulação indevida de ingressos.
- Proteger as operações administrativas.
- Manter as dependências actualizadas.

Estas recomendações não significam que todos os mecanismos já estejam implementados.
